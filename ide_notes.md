# IDE vs CLI Notes

**Удобно в VS Code:**
1. Панель Source Control — видно все изменения.
2. Просмотр Diff — наглядное сравнение версий.
3. Кнопка Commit (галочка) — экономит время.

**Удобно в терминале:**
1. Команда `git log --oneline --graph` — красивая история коммитов, которую в UI смотреть не так удобно.
